работе.

## Работа в проекте

- [Чаты](/chat/) — разговор с агентом, подтверждение действий, запланированные чаты.
- [Воркфлоу](/workflows/) — автоматические сценарии и история их запусков.
- [Артефакты](/artifacts/) — отчёты и страницы, которые создаёт агент, и их публикация.
- [Задачи](/jobs/) — фоновые задачи проекта.
- [Навыки](/skills/) — инструкции, которые агент применяет в работе.
- [Медиапланы](/media-plans/) — помесячные планы бюджета по каналам, на которые опирается агент.
- [Журнал действий](/action-log/) — действия агента и внешние изменения в рекламных кабинетах.
