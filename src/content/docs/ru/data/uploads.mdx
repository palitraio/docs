Через загрузку CSV в проект попадают данные, которых нет в коннекторах: офлайн-расходы, выгрузки
продаж из CRM, журналы звонков, справочники. Каждый файл становится таблицей проекта — её видно в
[исследователе данных](/data/explorer/). Рекламные метрики и события из файла можно сразу
сопоставить с системными полями Палитры, чтобы они участвовали в отчётах и атрибуции.

Загрузка идёт по шагам: тип данных → файл → схема и имя таблицы → маппинг полей. Историю всех
загрузок проекта и их статусы показывает экран «Логи».

Загружать файлы могут менеджеры проекта, а также владелец и администратор организации. Экран
«Логи» видят все участники проекта. Создавать таблицы из файлов можно на тарифе Pro: на тарифе без
этой функции кнопка создания таблицы неактивна, а при нажатии появляется «Пользовательские
таблицы не входят в ваш тариф» и кнопка «Повысить тариф».

## Как открыть экран

1. В боковой панели выберите проект и перейдите в раздел «Данные» — откроется «Пайплайн данных».
2. В блоке «Источники данных» найдите карточку «Загрузка CSV».
3. Нажмите «Загрузить», чтобы загрузить файл, или «Логи», чтобы посмотреть историю загрузок.

## Шаг 1. Выбрать тип данных

В блоке «Шаг 1 — Тип данных» выберите, что вы загружаете:

| Тип | Что подходит | Что дальше |
| --- | --- | --- |
| «Рекламные метрики» | Выгрузки из рекламных платформ: расходы, показы, клики по кампаниям. | Маппинг на поля `channel_daily`. |
| «Точки касания» | Офлайн-касания: звонки, SMS, промокоды, привязанные к каналу. | Маппинг на точки касания. |
| «Конверсии» | Продажи из CRM, журналы колл-трекинга, офлайн-покупки, лид-формы. | Маппинг на события проекта. |
| «Справочные данные» | Справочники и измерения: курсы, календари сезонности. | Без маппинга. |

### Скачать шаблон

Для типов «Рекламные метрики», «Точки касания» и «Конверсии» под карточками появляется блок «Нужен
шаблон?». Нажмите «Скачать шаблон» — скачается CSV-файл с одной строкой заголовков: стандартными
колонками для этого типа. Например, в шаблоне рекламных метрик колонки `date`, `source`, `medium`,
`campaign_id`, `adgroup_id`, `ad_id`, `impressions`, `clicks`, `spend`, `cost_currency` и
`revenue`.

Если назвать колонки своего файла так же, на шаге маппинга они сопоставятся автоматически.

## Шаг 2. Загрузить файл

1. После выбора типа станет доступен блок «Шаг 2 — Загрузка файла». Нажмите «Выбрать файл».
2. Выберите файл `.csv` или `.tsv` размером до 50 МБ.

Палитра загрузит файл и сама определит колонки и их типы. Пока идёт разбор, на экране «Загрузка и
разбор файла…».

Требования к файлу:

- первая строка — заголовки колонок, у каждой колонки своё название;
- разделитель — запятая, точка с запятой или табуляция;
- кодировка — UTF-8.

Если файл не подходит по расширению или размеру либо пустой, появится «Не удалось разобрать файл.
Убедитесь, что это корректный .csv или .tsv файл, и попробуйте снова.» Остальные ошибки разбора —
в разделе [«Ошибки в файле»](#ошибки-в-файле).

## Шаг 3. Проверить схему и задать имя таблицы

На шаге «Шаг 2 — Схема и имя таблицы» Палитра показывает найденные колонки и предпросмотр первых
пяти строк.

1. Проверьте «Имя таблицы». Оно предлагается по имени файла и всегда начинается с `udt_`.
2. В таблице колонок при необходимости переименуйте колонку в поле «Колонка» и поменяйте «Тип»:
   «Строка», «Число», «Дата», «Дата и время» или «Логический». В колонке «Пример» — значение из
   файла.
3. Сверьтесь с блоком «Предпросмотр (первые 5 строк)».
4. Нажмите «Далее — маппинг полей». Для справочных данных кнопка называется «Создать таблицу»: она
   сразу создаёт таблицу, и маппинг не нужен.

Кнопка неактивна, пока у какой-нибудь колонки пустое имя или с именем таблицы что-то не так:

- «Имя таблицы должно начинаться с udt_ и содержать только строчные буквы, цифры и символы
  подчёркивания.»
- «Таблица с таким именем уже существует. Выберите другое имя.»

Если файл не читается с выбранными типами, ошибка появится прямо в строке нужной колонки,
например: Строка 12, колонка «amount»: значение «abc» не является числом. Поменяйте тип колонки
и повторите.

## Шаг 4. Настроить маппинг полей

Маппинг объясняет Палитре, какая колонка файла чему соответствует. Шаг «Шаг 3 — Маппинг полей»
есть у рекламных метрик, точек касания и конверсий.

- Для «Рекламных метрик» колонки сопоставляются с полями `channel_daily` — дневной статистикой
  каналов.
- Для «Конверсий» события из файла сопоставляются с реестром [событий](/data/events/) проекта.
- Для «Точек касания» канальные колонки сопоставляются с точками касания.

Колонки, чьё имя совпадает с полем Палитры, сопоставляются автоматически. Остальное настройте в
редакторе: для каждого поля выберите «Источник» — колонку файла — и «Целевое поле».

Под редактором блок «Предпросмотр» показывает, что маппинг сделает с несколькими строками файла;
при этом ничего не сохраняется. Пока в маппинге есть ошибки, вместо результата видно «Исправьте
ошибки маппинга, чтобы увидеть результат».

Когда всё готово, выберите:

- «Сохранить маппинг и создать таблицу» — создать таблицу и сохранить маппинг;
- «Пропустить» — создать таблицу без маппинга. Маппинг можно настроить позже в
  [исследователе данных](/data/explorer/).

<Screenshot id="data-uploads-mapping" alt="Шаг «Маппинг полей»: редактор сопоставления колонок и блок «Предпросмотр»" />

Если маппинг не сохранился, появится «Не удалось сохранить маппинг. Проверьте сопоставления полей
и повторите попытку.» Таблица к этому моменту уже может быть создана — исправьте маппинг и
нажмите кнопку снова.

## Готово: таблица создана

После создания таблицы появится «Таблица udt_… создана» и сводка: число строк, колонок и, если
настроен маппинг событий, событий, с которыми сопоставлен файл.

- «Открыть в исследователе данных» — перейти к новой таблице.
- «Загрузить другой файл» — начать заново с первого шага.

Данные из файла загружаются в таблицу в фоне. Когда загрузка закончится, Палитра покажет
уведомление: «Добавлено N строк» или, если в файле были уже загруженные строки, «Добавлено N
строк, пропущено M дублей».

## Логи загрузок

Экран «Логи» показывает все загрузки CSV проекта, новые сверху. В каждой строке — имя файла,
таблица, сколько строк добавлено и сколько дублей пропущено, дата загрузки и статус.

| Статус | Что значит |
| --- | --- |
| «Ожидает создания таблицы» | Файл загружен, но таблица из него ещё не создана. |
| «Обрабатывается» | Данные из файла загружаются в таблицу. |
| «Готово» | Загрузка завершена. |
| «Ошибка» | Загрузка не удалась. Подсказка: «Загрузка завершилась с ошибкой. Попробуйте загрузить файл снова.» |

Загруженный файл ждёт создания таблицы 24 часа. Если за это время не дойти до создания таблицы,
загрузка получит статус «Ошибка» — загрузите файл заново.

Если загрузок ещё не было, на экране «Загрузок пока нет». Если список не загрузился — «Не удалось
загрузить список»; нажмите «Повторить».

## Ошибки в файле

Палитра проверяет файл и называет строку и колонку, где нашла проблему:

- «В файле нет строки заголовков. Укажите названия колонок в первой строке.»
- Строка 3: заголовок «price» встречается дважды. Дайте каждой колонке своё название.
- «Строка 7: 4 поля вместо 5» — в строке не хватает значений или есть лишние. Проверьте
  разделители и кавычки.
- «Строка 7 не читается как CSV. Проверьте кавычки и длину полей.»
- «Кодировка файла не поддерживается — пересохраните его в UTF-8.»
- «Разделитель в файле не поддерживается. Используйте запятую, точку с запятой или табуляцию.»
- «Файл больше допустимого размера.» — уменьшите файл до 50 МБ или разбейте его на части.
- «Загруженный файл больше недоступен — загрузите его заново.» — прошло больше 24 часов с
  загрузки. Начните с первого шага.

Ошибки, которые могут появиться уже после создания таблицы, во время фоновой загрузки:

- «Не удалось загрузить данные из файла. Попробуйте загрузить его снова.»
- «Не удалось узнать, чем закончилась загрузка файла. Проверьте её статус на странице задач.» —
  откройте раздел [«Задачи»](/jobs/) или экран «Логи».

Если файл не удалось отправить, появится «Не удалось загрузить файл. Проверьте подключение и
попробуйте снова.» Эту же ошибку увидят участники проекта без прав менеджера.
