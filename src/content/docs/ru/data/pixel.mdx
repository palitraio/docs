Тег Палитры — небольшой JavaScript-сниппет, который ставится на ваш сайт. Он присваивает
посетителю постоянный идентификатор, фиксирует источник трафика (линкер Палитры, UTM-метки или
referrer), сам отправляет просмотры страниц и позволяет отправлять ваши события — например,
покупки. Благодаря этому Палитра связывает визиты и конверсии на сайте с рекламными расходами.

Экран «Тег Палитры» открыт всем участникам проекта. На нём есть готовый код для установки и
статистика того, что тег уже прислал.

## Как открыть экран

1. В боковой панели выберите проект и перейдите в раздел «Данные» — откроется «Пайплайн данных».
2. В блоке «Источники данных» найдите карточку «Тег» и нажмите «Настроить».

На карточке «Тег» уже виден статус тега: «Получает данные», «Простаивает» или «Не настроено», —
и число событий за сегодня или время последнего события.

## Установить тег на сайт

1. В блоке «Установка» найдите «Шаг 1: добавьте базовый сниппет».
2. Нажмите «Копировать» в правом верхнем углу блока с кодом. Кнопка на две секунды сменится на
   «Скопировано».
3. Вставьте код перед закрывающим тегом `</head>` на каждой странице сайта.
4. Опубликуйте изменения на сайте и откройте любую его страницу.

Копируйте код с экрана, а не из этой статьи: в нём токен вашего проекта и адреса вашей установки
Палитры. Код выглядит так:

```html
<script>
  (function(w,d,s){ /* загружает тег асинхронно */ })(window,document,'palitra');
  palitra('init', '<токен проекта>', { endpoint: '<адрес приёма событий>' });
</script>
```

Просмотр страницы (`page_view`) тег отправляет сам — больше ничего для этого делать не нужно.

## Передавать вход пользователей

Шаг 2 на экране помечен «Опционально». Вызовите `identify` после того, как пользователь вошёл на
сайте, и передайте его ID из вашей системы:

```js
palitra('identify', currentUser.id);
```

Это связывает анонимные сессии посетителя с реальным пользователем — например, для сопоставления
с CRM.

## Отправлять свои события

Шаг 3, тоже «Опционально». Чтобы отправить конверсию или другое событие, вызовите `event` с
названием события и его параметрами:

```js
palitra('event', 'purchase', {
  value: 5900,
  currency: 'RUB',
  transaction_id: 'ORD-123',
  items: [{ id: 'SKU-1', price: 5900, quantity: 1 }]
});
```

Чтобы Палитра считала событие конверсией, отметьте его так в реестре [событий](/data/events/).

## Связать ID других систем аналитики

Шаг 4, «Опционально». ID систем веб-аналитики связываются с посетителем Палитры автоматически,
когда вы подключаете соответствующий [коннектор](/connectors/overview/). Для любого другого
внешнего идентификатора вызовите `link`:

```js
palitra('link', 'id_type', 'id_value');
```

Тип идентификатора пишется строчными латинскими буквами, цифрами и подчёркиваниями и начинается с
буквы, например `ga4_client_id`.

## Проверить, что данные приходят

После установки откройте любую страницу сайта и вернитесь на экран «Тег Палитры». Статус в правом
верхнем углу обновляется сам раз в 30 секунд.

| Статус | Что значит |
| --- | --- |
| «Получаем данные» | Последнее событие пришло не позже чем 15 минут назад. |
| «Ожидание» | События приходили раньше, но за последние 15 минут — ни одного. |
| «Данных нет» | От тега ещё не пришло ни одного события. |

Под статусом четыре счётчика: «Событий сегодня», «Всего событий», «Идентифицированных
пользователей» и «Анонимных пользователей». Внизу экрана — время последнего события: «Последнее
событие: …» или «Событий пока не было.».

Если статус остаётся «Данных нет» после того, как вы открыли страницу сайта, проверьте, что код
стоит на этой странице внутри `<head>` и что изменения на сайте опубликованы.

## Что собирает тег

В блоке «Что собирает тег» перечислены данные, которые тег передаёт в Палитру:

| Поле | Что это |
| --- | --- |
| `palitra_id` | Постоянный ID посетителя. |
| `session_id` | ID сессии, по нему события группируются в визиты. |
| `client_user_id` | ID пользователя из вашей системы — после вызова `identify`. |
| «Источник трафика» | Линкер Палитры, UTM-метки или referrer. |
| «События» | `page_view` автоматически и ваши события через `event`. |
| `linked_ids` | ID систем аналитики: из коннекторов и переданные через `link`. |

Линкер Палитры — параметр в рекламных ссылках. Как его проставляет коннектор, описано в разделе
«Автотегирование» статьи о [Яндекс Директе](/connectors/yandex-direct/).

## Ошибки

- «Не удалось загрузить конфигурацию тега» — экран не получил код для установки. Нажмите
  «Повторить».
- «Не удалось загрузить статус» рядом со статусом или «Статус недоступен.» внизу экрана — не
  загрузилась статистика; код установки при этом показан. Нажмите «Повторить» рядом со статусом.
