Раздел «Задачи» показывает работу, которую Палитра выполняет в фоне: синхронизации коннекторов,
загрузку CSV-файлов, приём данных вебхуков, пересчёт атрибуции, обновление дашбордов и фоновые
вызовы инструментов, которые агент запускает из чата. Здесь видно, что сейчас выполняется, что
завершилось и почему задача упала, — и здесь же упавшую задачу можно повторить.

Список задач видят все участники проекта. Повторять, отменять и удалять задачи могут менеджеры
проекта, а также владелец и администратор организации; у остальных кнопки действий в таблице нет.

## Как открыть раздел

1. Выберите проект в списке проектов в боковой панели.
2. Нажмите «Задачи» в боковой панели. Можно и с клавиатуры: ⌘ J на Mac или Ctrl J в Windows и
   Linux.

Если в чате агент запустил фоновую задачу, в сообщении появляется её карточка со статусом.
Нажмите на карточку — откроется раздел «Задачи» с этой задачей над списком (подробнее — в
разделе «Открыть задачу из чата» ниже).

## Что показывает таблица

Задачи идут от новых к старым. Колонки:

| Колонка        | Что в ней                                                                                 |
| -------------- | ----------------------------------------------------------------------------------------- |
| «Тип»          | Вид задачи — системное имя, например `etl_sync` (см. таблицу ниже).                       |
| «Коннектор»    | Коннектор, к которому относится задача, или «—».                                          |
| «Статус»       | Текущий статус; у упавшей задачи рядом значок с причиной ошибки.                          |
| «Прогресс»     | Полоса и процент выполнения, если задача их сообщает.                                     |
| «Начато»       | Когда задача началась, например «5 минут назад»; точное время — во всплывающей подсказке. |
| «Длительность» | Сколько задача шла; у выполняющейся время растёт на глазах.                               |
| «Повторы»      | Сколько раз задачу повторяли, например «×2».                                              |
| «Действия»     | Меню «…» с действиями над задачей.                                                        |

Статусы обновляются сами, перезагружать страницу не нужно. Внизу таблицы — номер страницы и
кнопки «Назад» и «Вперёд».

Типы задач, которые можно встретить в колонке «Тип»:

| Тип                     | Что это                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| `etl_sync`              | Синхронизация коннектора: загрузка данных из рекламного кабинета или аналитики.            |
| `csv_ingestion`         | Обработка загруженного CSV-файла.                                                          |
| `webhook_batch_ingest`  | Приём пачки данных, пришедших через вебхук.                                                |
| `attribution_recompute` | Пересчёт атрибуции.                                                                        |
| `connector_reprocess`   | Пересборка событий из уже загруженных данных коннектора после сохранения мэппинга событий. |
| `tool_run`              | Фоновый вызов инструмента коннектора, запущенный агентом из чата.                          |
| `artifact_refresh`      | Обновление дашборда-артефакта по запросу.                                                  |
| `reconciliation_sync`   | Сверка данных из старых версий Палитры. Новые такие задачи не создаются.                   |
| `workflow_…`            | Шаг [воркфлоу](/workflows/).                                                               |

## Отфильтровать задачи по статусу

1. Откройте список статусов над таблицей — по умолчанию в нём выбрано «Все статусы».
2. Выберите статус, например «Ошибка». Чтобы снова видеть всё, выберите «Все статусы».

Фильтр сбрасывается, когда вы переключаетесь на другой проект.

## Статусы задач

| Статус             | Что значит                                                                              |
| ------------------ | --------------------------------------------------------------------------------------- |
| «Ожидание»         | Задача в очереди и ещё не началась.                                                     |
| «Выполняется»      | Задача идёт.                                                                            |
| «Отменяется…»      | Отмену запросили, задача остановится в ближайшей безопасной точке.                      |
| «Завершено»        | Задача выполнена успешно.                                                               |
| «Ошибка»           | Задача упала. Причина — в подсказке у значка рядом со статусом.                         |
| «Отменено»         | Задачу отменили.                                                                        |
| «Отложено»         | Синхронизацию остановила квота API платформы, она продолжится позже.                    |
| «Исход неизвестен» | Фоновый вызов инструмента мог изменить данные на платформе, но результат не сохранился. |

**«Отложено».** Подсказка у значка часов объясняет: «Закончилась квота API платформы. Следующая
синхронизация запустится после … и продолжит с этого места.» Ничего делать не нужно: следующая
синхронизация коннектора будет новой задачей и продолжит с того места, где остановилась эта.

**«Исход неизвестен».** Подсказка: «Вызов мог изменить данные на платформе. Проверьте там, прежде
чем повторять.» Откройте рекламный кабинет и убедитесь, что изменение не применилось, прежде чем
запускать его ещё раз.

## Понять, почему задача упала

Наведите курсор на красный значок рядом со статусом «Ошибка». В подсказке две строки: что
случилось и что сделать. Частые причины:

| Что случилось                                                                        | Что сделать                                                   |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| «Срок действия авторизации коннектора истёк.»                                        | «Переподключите учётные данные в настройках коннектора.»      |
| «У аккаунта нет доступа к запрошенным данным.»                                       | «Попросите владельца аккаунта выдать доступ и повторите.»     |
| «Коннектор отключён, поэтому синхронизация не запустилась.»                          | «Включите коннектор перед повтором.»                          |
| «Уже шла другая синхронизация этого коннектора, поэтому эта не запустилась.»         | «Дождитесь завершения той синхронизации.»                     |
| «Платформа раз за разом возвращала временную ошибку, и попытки повтора закончились.» | «Повторите задачу.»                                           |
| «Платформа отклонила запрос.»                                                        | «Эту ошибку нельзя повторить — обратитесь в поддержку.»       |
| «Сохранённый мэппинг событий коннектора больше не действителен.»                     | «Откройте мэппинг событий коннектора и сохраните его заново.» |
| «Задача превысила лимит времени.»                                                    | «Повторите её или сузьте запрос.»                             |
| «Инструмент запрещён для этого проекта.»                                             | «Разрешите его в правах коннектора.»                          |

К тексту ошибки может добавляться деталь, например «Код платформы: …» или «Таблица: …». Полный
текст ошибки без обрезки виден в карточке задачи, открытой из чата.

## Открыть задачу из чата

Когда агент запускает фоновую задачу, в чате появляется карточка с типом задачи и статусом
(«Ожидает», «Выполняется», «Завершено» и т. д.). Нажмите на неё:

1. Откроется раздел «Задачи», а над списком — карточка этой задачи.
2. В карточке: статус, «Коннектор», «Начата», «Завершена», а у отложенной синхронизации —
   «Продолжится». Для упавшей задачи ниже выводится полный текст ошибки.
3. Чтобы вернуться к обычному списку, нажмите «Показать все задачи».

Карточка показывает задачу, даже если её нет на текущей странице списка или она не подходит под
выбранный фильтр. Если задачу удалили, в карточке будет «Задача не найдена».

## Повторить задачу

Повторить можно задачу со статусом «Ошибка» или «Отменено».

1. В строке задачи нажмите «…» в колонке «Действия».
2. Выберите «Повторить».

Задача вернётся в статус «Ожидание», а счётчик в колонке «Повторы» увеличится на один. Задача
повторяется на месте, новой строки не появляется.

<Screenshot
  id="jobs-actions-menu"
  alt="Меню действий задачи с пунктами «Повторить», «Отменить» и «Удалить»"
/>

Пункта «Повторить» нет, если ошибка помечена как неповторяемая («Платформа отклонила запрос.»).
Для шага воркфлоу вместо него стоит «Повторить в Workflow»: он ведёт в раздел
[«Воркфлоу»](/workflows/), шаги повторяются из запуска воркфлоу. Задачу старше 30 дней повторить
нельзя.

Если повтор не удался, Палитра покажет причину:

- «Для этого коннектора уже выполняется синхронизация. Повторите попытку после её завершения.»
- «Повторить можно только упавшую или отменённую задачу.» — статус задачи уже сменился.
- «Повтор недоступен: исходные параметры задачи не сохранены.»
- «Вызов с записью нельзя повторить. Запустите его заново из чата.» — фоновый вызов, который
  меняет данные на платформе, повторяется только новым запросом агенту.
- «Слишком много фоновых вызовов. Попробуйте позже.»
- «Не удалось достучаться до брокера задач. Оставляем задачу в очереди — повторите, если она не
  запустится в ближайшее время.» — задача остаётся в статусе «Ожидание».
- «У вас нет прав на повтор этой задачи.»

## Отменить задачу

Отменить можно задачу в статусе «Ожидание» или «Выполняется».

1. В строке задачи нажмите «…».
2. Выберите «Отменить».

Задача в очереди отменяется сразу и получает статус «Отменено». Выполняющаяся задача сначала
показывает «Отменяется…» и останавливается в ближайшей безопасной точке.

Пункта «Отменить» нет у шагов воркфлоу (их отменяют вместе с запуском воркфлоу) и у
выполняющегося фонового вызова, который меняет данные на платформе: прерывать его на середине
небезопасно.

## Удалить задачу

Удалить можно только завершённую задачу: «Завершено», «Ошибка», «Отменено» или «Отложено».

1. В строке задачи нажмите «…» и выберите «Удалить».
2. В окне «Удалить задачу?» нажмите «Удалить». Кнопка «Оставить» закрывает окно.

Задача и её сохранённый результат удаляются безвозвратно.

## Очистить завершённые задачи

Чтобы удалить сразу много старых задач:

1. Нажмите «Очистить завершённые» над таблицей.
2. В окне «Очистить завершённые задачи?» отметьте «Статусы», которые нужно удалить:
   «Выполнена», «Ошибка», «Отменена», «Отложена». По умолчанию отмечены все.
3. В блоке «Завершены» выберите давность: «В любое время», «Больше суток назад», «Больше 7 дней
   назад» или «Больше 30 дней назад».
4. Нажмите «Удалить».

Палитра сообщит, сколько задач удалено, например «Удалено 12 задач». Выполняющиеся и ожидающие
задачи не удаляются. Кнопку «Очистить завершённые» видят только те, кто может управлять задачами.

## Если что-то не загружается

- «Обновления в реальном времени приостановлены» — соединение для живых обновлений потеряно,
  статусы обновляются периодически и могут отставать. Нажмите «Переподключиться». Если в тексте
  предлагают войти снова, обновите страницу или войдите заново.
- «Не удалось загрузить задачи» — нажмите «Повторить».
- «Задач пока нет» — в проекте ещё не было фоновой работы. Задачи появятся, когда она начнётся:
  например, синхронизация коннектора, загрузка данных или фоновый вызов из чата.
