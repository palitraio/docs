Приложение Палитры для компьютера открывает ту же Палитру, что и браузер: те же чаты, проекты
и данные под вашей учётной записью. Отличия такие:

- **Системные уведомления.** Когда окно приложения свёрнуто или закрыто, новые уведомления
  приходят как обычные уведомления macOS или Windows. Нажатие на уведомление открывает
  приложение на нужной странице.
- **Непрочитанные на значке.** На macOS значок в Dock показывает число непрочитанных
  уведомлений текущего проекта, на Windows на значке в панели задач появляется красная точка.
- **Работа в фоне.** Если закрыть окно, приложение продолжает работать и присылать
  уведомления: на macOS оно остаётся в Dock, на Windows — в области уведомлений рядом с
  часами. Полностью приложение закрывается командой «Выйти».

## Установка

Скачайте приложение на странице [ru.palitra.io/download](https://ru.palitra.io/download/):

| Система                             | Файл                     |
| ----------------------------------- | ------------------------ |
| macOS, Mac с процессором M1 и новее | `.dmg` для Apple Silicon |
| macOS, Mac с процессором Intel      | `.dmg` для Intel         |
| Windows 10 и 11, 64-бит             | установщик `.exe`        |

Пока приложение не подписано сертификатом Apple и Microsoft, поэтому при первом запуске
система попросит подтвердить, что вы ему доверяете. Это нужно один раз.

**macOS**

1. Откройте `.dmg` и перетащите «Палитру» в папку «Программы».
2. Запустите «Палитру». macOS покажет предупреждение — нажмите «Готово».
3. Откройте «Системные настройки» → «Конфиденциальность и безопасность», прокрутите до
   раздела «Безопасность» и нажмите «Всё равно открыть» рядом с сообщением о «Палитре». Кнопка
   доступна около часа после попытки запуска.
4. Подтвердите паролем от Mac и нажмите «Открыть».

**Windows**

1. Запустите `Palitra-Setup.exe`.
2. Если появится окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем
   «Выполнить в любом случае».
3. После установки приложение откроется само.

Чтобы приложение запускалось при входе в систему, включите «Запускать при входе» в меню
значка: на macOS — правый клик по значку в Dock, на Windows — правый клик по значку в области
уведомлений.

## Вход

Войти можно так же, как в браузере:

- **Почта и пароль** — прямо в окне приложения.
- **Единый вход (SSO) организации** — страница входа вашей компании открывается в том же окне.
  Над ней видно, на каком сайте вы вводите пароль, и есть кнопка «Отменить вход».
- **Яндекс** — во всплывающем окне приложения, как в браузере.
- **Google** — в вашем браузере: Google не разрешает входить через встроенные окна
  приложений. После входа браузер покажет «Вернитесь в приложение Палитра», и приложение
  откроется уже с выполненным входом. Если этого не произошло, нажмите «Открыть Палитру» на
  той же странице. Не пересылайте эту ссылку другим людям.

Если в вашей организации обязателен вход через SSO, вход через Google недоступен — браузер
сообщит об этом, и войти нужно через SSO в приложении.

## Сервер

По умолчанию приложение подключается к Палитре в облаке. Название и адрес сервера видны в
заголовке окна, например «Палитра — app.ru.palitra.io».

Если у вашей компании свой сервер Палитры, выберите «Подключиться к другому серверу»:

- на macOS — в меню **Палитра** в строке меню или правым кликом по значку в Dock;
- на Windows — в меню **Палитра** окна приложения или правым кликом по значку в области
  уведомлений.

Введите адрес сервера (например, `palitra.example.com`) и нажмите «Подключиться». Приложение
проверит, что по этому адресу работает Палитра, и запомнит выбор. Поддерживаются только
защищённые адреса (`https`). Вернуться к облаку можно там же кнопкой «Вернуться к Палитре RU».
Вход на каждом сервере свой.

## Обновления

Приложение не обновляется само. Когда выходит новая версия, приходит уведомление «Доступна
новая версия», а в меню значка появляется одноимённый пункт. Оба открывают страницу
загрузки: скачайте новую версию и установите её поверх текущей, вход сохранится.

## Если что-то пошло не так

- **«Не удалось открыть Палитру».** Приложение не смогло связаться с сервером: проверьте
  интернет и нажмите «Повторить». Если адрес сервера неверный, нажмите «Сменить сервер».
- **«Нужно обновить приложение».** Ваша версия приложения слишком старая для этого сервера.
  Нажмите «Скачать новую версию» и установите её поверх текущей.
