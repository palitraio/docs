Коннектор UIS (бывший CoMagic) загружает в Палитру звонки, заявки, чаты и сделки с одного
сайта в UIS. Каждое обращение связывается с рекламой, которая привела посетителя, через Линкер
Палитры. Телефоны и e-mail хранятся только в виде хешей с ключом проекта.

Один коннектор работает с одним сайтом UIS. Коннектор только читает данные: в UIS он ничего не
меняет.

UIS нет в мастере настройки после регистрации: там подключаются только сервисы со входом
через OAuth. Подключайте UIS из раздела «Коннекторы».

## Подключение из раздела «Коннекторы»

1. В боковой панели откройте «Коннекторы» и перейдите на вкладку «Маркетплейс». UIS находится
   в категории «Коллтрекинг».
2. На карточке «UIS» нажмите «Подключить». Откроется страница «Подключение UIS».
3. **«Авторизация».** Сначала разрешите адрес Палитры в кабинете UIS — подробнее ниже. Затем
   вставьте ключ в поле «API-токен». Подсказка под полем: «API-токен из настроек API в кабинете
   UIS.» Если ключ UIS уже сохранён в Палитре, можно выбрать существующие учётные данные.
   Отметьте «Сохранить на уровне организации», если тот же ключ понадобится в других проектах.
4. Нажмите «Продолжить». Палитра запросит у UIS сайты, которые видны по этому ключу.
5. **«Выбор аккаунта».** В списке «Выберите субаккаунт» выберите сайт. Сайты подписаны
   доменом. Шаг появляется, даже если сайт один.
6. **«Проверка».** Проверьте настройки и нажмите «Готово». Палитра подключит коннектор и
   проверит доступ.

Если UIS не вернул ни одного сайта, вместо выбора из списка мастер покажет шаг «Параметры» с
полем «ID сайта».

Сайт после подключения не меняется. Чтобы загружать данные другого сайта, подключите UIS ещё
раз кнопкой «Подключить ещё» и выберите этот сайт.

Шагов «Разрешения», «Ограничения», «Автотегирование» и «Сопоставление событий» у UIS нет. Общее
устройство мастера описано в [обзоре коннекторов](/connectors/overview/).

### Разрешите адрес Палитры

UIS принимает запросы к API только с адресов из списка разрешённых. На шаге «Авторизация»
мастер показывает блок «Разрешите адрес Палитры»:

1. Скопируйте значение из поля «Адрес для разрешения» кнопкой «Копировать».
2. Добавьте его в кабинете UIS. Путь указан в блоке: «В кабинете UIS: Администратор → Аккаунт →
   Правила и настройки безопасности → API.»
3. Вернитесь в мастер и продолжите подключение.

Если адреса нет в списке, UIS отклонит ключ. Если в блоке есть пометка «У Палитры пока нет
постоянного адреса», показанное значение разрешает запросы к API с любого адреса.

Настраивать в кабинете UIS уведомления, вебхуки или выгрузку файлов для коннектора не нужно.

## Какие данные загружаются

Палитра загружает из UIS по выбранному сайту:

- звонки — становятся событиями `phone_call`, с длительностью разговора и отметкой о
  пропущенном звонке;
- заявки — событиями `submit_form`, с типом и названием формы;
- чаты — событиями `chat_start`, с каналом чата и числом сообщений;
- сделки — событиями `purchase`.

Сделка загружается, только если она выросла из звонка, заявки или чата этого сайта. Каждая
сделка — одна покупка: Палитра берёт её текущий этап и выручку на нём, в рублях. Сделка без
выручки покупкой не считается. Когда сделка переходит на другой этап, покупка обновляется, а не
дублируется.

Вместе с каждым обращением загружаются страница входа, источник перехода, UTM-метки и поисковый
запрос. По ним Палитра определяет рекламу, которая привела посетителя: в первую очередь по
[Линкеру Палитры](/data/pixel/) в ссылке, затем по UTM-меткам и сайту-источнику. Так звонки и
сделки связываются с расходами рекламных кампаний.

Чтобы связать обращение с посетителем сайта, Палитра использует идентификатор посетителя UIS,
ClientID Метрики и Google Analytics, а также хеши телефона и e-mail.

Телефоны и e-mail Палитра не хранит: при загрузке они заменяются хешами с ключом проекта. Если
значение не похоже на телефон или e-mail, оно не сохраняется.

UIS дополняет звонки и заявки задним числом, поэтому при каждой синхронизации Палитра заново
читает последние 30 дней. Синхронизация идёт автоматически каждые 4 часа.

Как работать с событиями проекта, описано в статье [События](/data/events/).

## Что умеет агент

У коннектора UIS нет инструментов агента, поэтому шага «Разрешения» нет.

## Заменить ключ

Если ключ UIS истёк, заблокирован или перевыпущен:

1. На карточке коннектора нажмите на три точки и выберите «Настроить». Откроется страница
   «Настройки UIS».
2. На шаге «Авторизация» нажмите «Подключить другой аккаунт» и вставьте новый ключ в поле
   «API-токен».
3. Перейдите к шагу «Проверка» и нажмите «Сохранить».

## Частые проблемы

### При подключении

Сообщения об ошибках мастер показывает на шаге «Авторизация» — под полем ключа или над формой.

**«UIS отклонил запрос: адреса Палитры нет в списке разрешённых.»** Добавьте адрес из блока
«Разрешите адрес Палитры» в кабинете UIS и попробуйте ещё раз.

**«UIS не узнаёт этот API-ключ.»** Скопируйте ключ заново в разделе управления пользователями
кабинета UIS.

**«Срок действия API-ключа UIS истёк.»** Выпустите новый ключ в разделе управления
пользователями кабинета UIS и вставьте его в поле.

**«API-ключ UIS заблокирован.»** Разблокируйте его или выпустите новый в разделе управления
пользователями кабинета UIS.

**«У пользователя UIS, которому принадлежит ключ, нет доступа к отчётам.»** Ключ работает с
правами своего пользователя. Выдайте ему доступ в разделе управления пользователями кабинета
UIS и попробуйте ещё раз.

**«Аккаунт UIS отключён.»** Обратитесь в поддержку UIS, чтобы восстановить аккаунт, и
попробуйте ещё раз.

**«Не удалось загрузить аккаунты».** Палитра не смогла получить список сайтов по ключу. Нажмите
«Повторить». Если ошибка повторяется, проверьте ключ.

**«Этого аккаунта больше нет. Выберите другой.»** Выбранный сайт удалён в UIS. Выберите другой
сайт из списка. Если удалены все сайты, мастер вернёт вас на шаг «Авторизация» с сообщением
«Ключ UIS больше не даёт доступа ни к одному аккаунту». Проверьте доступ ключа в кабинете UIS или
укажите другой ключ.

**«Этот аккаунт уже подключён в проекте.»** Этот сайт уже подключён. Нажмите «Открыть
подключённый коннектор» или выберите другой сайт.

### После подключения

Если с коннектором что-то не так, на его карточке в разделе «Коннекторы» появляется значок.
Наведите на него, чтобы увидеть, что случилось и что делать.

**«Срок авторизации истёк.»** UIS отклонил ключ или адрес Палитры: ключ неверный, истёк или
заблокирован, адреса Палитры нет в списке разрешённых или аккаунт UIS отключён. Проверьте
список разрешённых адресов в кабинете UIS. Если дело в ключе, [замените его](#заменить-ключ).

**«У коннектора нет доступа к этому аккаунту.»** У пользователя, которому принадлежит ключ, нет
прав на отчёты или он больше не видит выбранный сайт. Выдайте права в кабинете UIS или
[замените ключ](#заменить-ключ) на ключ пользователя, который видит сайт.

**«Лимит запросов к API сервиса пока исчерпан.»** У UIS есть лимит запросов в минуту и в
сутки. Ничего делать не нужно: синхронизация продолжится, когда лимит обновится.

**«Часть аккаунта в сервисе отключена, поэтому некоторые данные не загружаются.»** В аккаунте
UIS не подключён компонент, без которого недоступен один из отчётов. Эти данные
не загружаются, а загруженные раньше сохраняются. Включите компонент в кабинете UIS — данные
загрузятся при следующей синхронизации.

**«Сервис прекращает поддержку версии API, которую использует Палитра.»** Палитра обновит
коннектор до отключения версии. Ничего делать не нужно, если предупреждение не останется
надолго.

**«Последняя синхронизация завершилась ошибкой.»** Палитра повторит попытку при следующей
синхронизации. Если ошибка повторяется, нажмите «Синхронизировать» в меню карточки коннектора
или напишите в поддержку.
