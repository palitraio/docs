Коннектор Adjust загружает в Палитру данные одного мобильного приложения: установки,
повторные вовлечения, события в приложении, доход от рекламы, подписки и удаления. Эти данные
приходят из Adjust через серверные колбэки и выгрузку в облачное хранилище, а дневная
статистика приложения — через синхронизацию. Рекламные идентификаторы устройств, e-mail и
телефоны хранятся только в виде хешей. Агент получает инструменты для работы с аккаунтом Adjust.

Подключение состоит из двух частей: сначала вы подключаете коннектор в Палитре, затем
настраиваете колбэки и выгрузку в кабинете Adjust.

## Доступность на тарифе

Мобильные трекеры доступны не на всех тарифах. Если ваш тариф их не включает, на карточке
Adjust в маркетплейсе стоит отметка «Доступно на Pro», а кнопка «Подключить» неактивна. Нажмите
на неё: появится «Мобильные трекеры не входят в ваш тариф» и кнопка «Повысить тариф».
Подробнее — в разделе [Оплата](/organization/billing/).

В мастере настройки после регистрации Adjust не предлагается: подключите его из раздела
«Коннекторы».

## Подключение из раздела «Коннекторы»

1. В боковой панели откройте «Коннекторы», перейдите на вкладку «Маркетплейс» и выберите
   категорию «Мобильные трекеры».
2. На карточке «Adjust» нажмите «Подключить». Откроется страница «Подключение Adjust».
3. **«Авторизация».** Вставьте токены из кабинета Adjust:
   - «API-токен» — обязательно. В Adjust он находится в Account settings → My profile → API
     Token. Если вы входите в Adjust через SSO, токена в кабинете нет: запросите его у
     представителя Adjust или в support@adjust.com.
   - «S2S-токен» — необязательно. Он нужен только инструментам агента, которые отправляют
     события с сервера и запросы на удаление данных пользователя.

   Нажмите «Продолжить»: Палитра загрузит приложения, которые видны с этим токеном.

4. **«Выбор аккаунта».** В списке «Выберите приложение» выберите приложение. Один коннектор
   загружает одно приложение; для второго приложения того же токена подключите ещё один
   коннектор.
5. **«Разрешения».** Для каждого инструмента агента выберите: «Всегда разрешать», «Требует
   подтверждения» или «Заблокировано».
6. **«Проверка».** Проверьте настройки и нажмите «Готово». Палитра подключит коннектор и
   проверит доступ.
7. **«Сопоставление событий».** Этот шаг идёт после подключения. Подробнее — ниже.

Приложение нельзя сменить после подключения: «Чтобы сменить приложение, удалите коннектор и
подключите заново.»

Общие правила мастера, сохранение учётных данных на уровне организации и повторное
использование уже сохранённых токенов описаны в [обзоре коннекторов](/connectors/overview/).

## Сопоставление событий

Здесь события в приложении из Adjust связываются с событиями проекта. Список берётся из
настроек приложения в Adjust и из событий, которые уже пришли; событие узнаётся по его токену в
Adjust, поэтому переименование в Adjust сопоставление не ломает.

Установки, повторные вовлечения, показы рекламы, подписки и удаления импортируются всегда —
сопоставлять их не нужно. Для событий в приложении:

- пока сопоставлений нет, все события импортируются под своими именами;
- как только вы сопоставите хотя бы одно, события без сопоставления не импортируются.

Нажмите «Сохранить сопоставление» или «Пропустить». К шагу можно вернуться позже в
настройках коннектора.

## Настройка в Adjust после подключения

Данные по устройствам Палитра не запрашивает у Adjust сама: их присылает Adjust. Поэтому после
подключения настройте в кабинете Adjust колбэки и, по желанию, выгрузку в хранилище.

Всё нужное для этого — на странице настроек коннектора: в разделе «Коннекторы» нажмите на
название коннектора Adjust. Карточки «Push» и «Выгрузка в облачное хранилище» видят только
менеджеры проекта и выше: в них хранятся секретные адреса и ключи.

### Колбэки

На карточке «Push» — блок «Добавьте колбэки в Adjust вручную» со списком триггеров: «Установка»,
«Переустановка», «Реатрибуция», «Реатрибуция с переустановкой», «Событие в приложении», «Доход
от рекламы», «Подписка», «Удаление приложения», «Обновление атрибуции», «Удалённый
пользователь (GDPR)». У каждого триггера две кнопки копирования: URL и тело запроса. Адреса
скрыты, нажмите «Показать», чтобы их увидеть.

Для каждого триггера:

1. В Adjust откройте AppView → All apps → ваше приложение → Data management → Server callbacks
   → Add callback.
2. В Callback trigger выберите триггер.
3. Вставьте URL в Server endpoint.
4. В Request method выберите POST.
5. Вставьте тело запроса.

Над списком показано состояние канала: «Ждём первое сообщение», «Работает» или «Работает с
перебоями». Если Палитра отклоняет сообщения, на карточке появится «Отклонено … сообщений:
неверный токен или чужое приложение.»

Тестовые колбэки из песочницы Adjust Палитра сохраняет, но в события проекта они не попадают.

### Выгрузка в облачное хранилище

Выгрузка необязательна, но рекомендуется: она восстанавливает то, что не дошло колбэками, —
Adjust повторяет неудавшийся колбэк только 24 часа.

На карточке «Выгрузка в облачное хранилище» — значения для настройки: «Bucket URL», «Access key
ID», «Secret access key», «CSV definition» и список «Триггеры». В Adjust:

1. Откройте AppView → All apps → ваше приложение → Data management → Cloud storage upload →
   Configure → New setup.
2. В Storage provider выберите Custom S3.
3. Заполните Access key ID, Secret access key и Bucket URL. Region оставьте пустым.
4. В Triggers отметьте триггеры из списка на карточке.
5. Вставьте CSV definition целиком, не меняя: файлы по изменённой CSV definition Палитра не
   прочитает.
6. Нажмите Save and apply.

На карточке видно, сколько файлов ждут импорта, и список «Не импортированные файлы» с
причинами. Выгруженные файлы хранятся не больше 7 дней. Если на карточке появилось «CSV
definition изменилась — скопируйте её в Adjust заново: пока там старая, файлы не
импортируются.», скопируйте новую CSV definition в Adjust.

Для каждого приложения нужен свой коннектор и своё хранилище: файлы другого приложения
Палитра не импортирует.

### Смена токена и ключа

Адрес колбэков и ключ хранилища можно заменить кнопками «Сменить токен адреса» на карточке
«Push» и «Сменить ключ хранилища» на карточке выгрузки.
Старое значение перестаёт работать сразу, а Adjust об этом не узнаёт: сразу после смены вставьте
новые адреса или ключ в настройки Adjust, иначе колбэки будут отклоняться, а выгрузки —
завершаться ошибкой.

## Какие данные загружаются

Через колбэки и выгрузку в хранилище Палитра получает действия на устройствах:

- установки и переустановки, реатрибуции, удаления приложения;
- события в приложении;
- доход от рекламы и подписки;
- обновления атрибуции — они сохраняются, но событий проекта не создают.

Установки, повторные вовлечения, показы рекламы, подписки и удаления становятся событиями
проекта, события в приложении — по сопоставлению. Данные по устройствам хранятся 90 дней.

Если ссылка Adjust размечена параметром `palitra` (меткой Палитры), установка связывается с
рекламой по этой метке; без метки — по атрибуции Adjust.

Через синхронизацию Палитра загружает дневную статистику приложения в часовом поясе
коннектора — по партнёрам, сетям, кампаниям, группам объявлений, креативам и ОС, а также по
странам: установки, клики, показы, сессии, реатрибуции, переустановки, удаления, события,
события с доходом, доход, доход от рекламы, расходы и установки SKAdNetwork. Синхронизация
идёт каждые 6 часов; первая загружает статистику за последние 400 дней.

После каждой синхронизации Палитра сверяет установки и события, пришедшие колбэками и
выгрузкой, с дневной статистикой Adjust и предупреждает, если строк по устройствам заметно
меньше.

### Личные данные

Рекламные идентификаторы устройств хранятся только в виде хешей. ID пользователя приложения
Палитра берёт из параметра колбэка, который приложение задаёт в SDK Adjust. Если в нём e-mail
или телефон, сохраняется только хеш. Когда Adjust сообщает об удалённом пользователе (триггер
«Удалённый пользователь (GDPR)»), Палитра удаляет данные этого устройства.

## Параметры коннектора

После подключения в настройках коннектора появляется шаг «Параметры»:

- «Часовой пояс отчётов (UTC±)» — часовой пояс, в котором Adjust считает дни отчётов. При
  подключении берётся часовой пояс проекта. «Изменение заново загружает недавние данные
  коннектора (окно полной синхронизации).»
- «Параметр с ID пользователя приложения» — параметр колбэка из SDK Adjust, в котором
  приложение передаёт ID пользователя. Пусто — используется `user_id`. Этот параметр входит в
  CSV definition: после изменения скопируйте CSV definition с карточки выгрузки в Adjust заново.
- «Приложение» — не меняется после подключения.

Изменения сохраняются на шаге «Проверка» кнопкой «Сохранить».

## Что умеет агент

Агент работает с Adjust через инструменты. Их список и разрешения видны на шаге «Разрешения».

**Чтение и отчёты.** По умолчанию разрешено всегда. Например: «Статистика приложения»,
«Сводный отчёт», «Отчёт в CSV», «Список приложений», «Данные приложения», «Настройки
приложения», «Список трекинговых ссылок», «Список партнёров», «Данные устройства», «Лимит
диплинков», «QR-код картинкой».

**Изменения.** По умолчанию требуют вашего подтверждения. Например: «Создать трекинговую
ссылку», «Изменить трекинговую ссылку», «Заблокировать трекинговую ссылку», «Создать диплинк»,
«Создать приложение», «Изменить приложение», «Создать события приложения», «Изменить настройки
подписи SDK».

**Необратимые действия.** Тоже требуют подтверждения; то, что они удаляют или отзывают,
восстановить нельзя: «Забыть тестовое устройство», «Запросить удаление данных пользователя»,
«Отозвать секрет SDK», «Отозвать устаревшие секреты SDK».

Инструменты «Отправить событие с сервера», «Отправить сессию с сервера», «Передать доход от
рекламы с сервера», «Настроить передачу данных партнёрам» и «Запросить удаление данных
пользователя» работают, только если в учётных данных сохранён «S2S-токен».

## Отключение

Колбэки и выгрузку в хранилище Палитра не может убрать из Adjust сама. Когда вы удаляете
коннектор, появится окно «Adjust отключён» со списком того, что сделать в Adjust вручную:
удалить колбэки Палитры и отключить выгрузку Custom S3. Выполните шаги и нажмите «Готово».

## Частые проблемы

Если с коннектором что-то не так, на его карточке в разделе «Коннекторы» появляется значок.
Наведите на него, чтобы увидеть, что случилось и что делать. Те же сообщения показаны на
странице коннектора, со ссылками «Открыть панель Push» и «Открыть карточку хранилища».

**«Adjust не принял токен. Скопируйте его заново в Account settings → My profile → API
Token.»** Токен вставлен с ошибкой или больше не действует. Скопируйте его заново.

**«Срок авторизации истёк.»** Adjust перестал принимать API-токен. Откройте настройки
коннектора, на шаге «Авторизация» нажмите «Подключить другой аккаунт», вставьте актуальный
API-токен и сохраните на шаге «Проверка».

**«У пользователя этого токена нет доступа к приложению — попросите администратора Adjust
выдать доступ.»** или **«У коннектора нет доступа к этому аккаунту.»** Пользователь, чей токен
вы вставили, не видит приложение. Попросите администратора Adjust выдать доступ.

**«Это приложение не видно с этим токеном.»** Выберите другое приложение или вставьте токен
пользователя, которому видно нужное.

**«Это приложение уже подключено в проекте как «…».»** Одно приложение нельзя подключить в
проект дважды. Откройте уже подключённый коннектор.

**«Давно нет push-сообщений, хотя сервис видит новые установки.»** Проверьте в Adjust, что
колбэки с карточки «Push» добавлены для всех триггеров.

**«Палитра не смогла прочитать часть push-сообщений.»** Сверьте колбэки в Adjust с карточкой
«Push»: URL, метод POST и тело. Если предупреждение повторяется, напишите в поддержку.

**«Во входящих данных нет полей, которые должен заполнять сервис.»** Колбэки или CSV
definition в Adjust отличаются от выданных Палитрой. Скопируйте значения с карточек
коннектора в Adjust заново.

**«В данных по устройствам меньше строк, чем в отчётах сервиса.»** Часть колбэков не дошла.
Такие пропуски восстанавливает выгрузка в хранилище: проверьте, что она настроена.

**«Файлов из облачного хранилища нет, хотя колбэки приходят.»** Сверьте настройку выгрузки в
Adjust с карточкой «Выгрузка в облачное хранилище».

**«Часть выгруженных файлов не импортирована.»** Какие файлы не импортированы и почему —
на карточке хранилища. Частая причина: «CSV definition отличается от выданной Палитрой».

**«Выгруженные файлы ждут импорта.»** или **«Выгруженные файлы скоро удалятся, так и не
импортировавшись.»** Палитра импортирует файлы сама. Если предупреждение не пропадает, напишите
в поддержку.

**«Последняя синхронизация завершилась ошибкой.»** Палитра повторит попытку при следующей
синхронизации. Если ошибка повторяется, запустите синхронизацию вручную или напишите в
поддержку.
